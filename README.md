### 👋 Sobre mim

Sou formado em **Análise e Desenvolvimento de Sistemas** e construo aplicações web e soluções de dados do problema ao deploy. Meu foco é entregar coisa que funciona em produção: banco com regras de acesso bem feitas, testes automatizados, CI e documentação que deixa o projeto fácil de manter.

- 🔭 Hoje: produto full stack com **Next.js + Supabase** e pipelines de dados em **Python**
- 🎯 Aberto a vagas de **desenvolvimento full stack, back-end e dados**
